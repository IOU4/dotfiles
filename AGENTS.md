# General instructions for agents:
  - do not create, edit, or delete files or otherwise change project state unless the user explicitly instructs you to make changes.
  - when requested to change something output the change plan briefly and wait for confirmation.
  - requests for analysis, explanation, or review do not authorize changes.
  - focus only on the given task don't make other changes unless requested to.
  - don't suggest next steps unless requested to.
  - if task is not clear in some parts, or need more input, always ask for clarifications, don't make assumptions.
  - always be brief in your answers and only mention other considiration briefly if they are important to the task.
  - only warn the user if there are serious missed side effect.
  - never git add/commit/push unless explicitly instructed to.
